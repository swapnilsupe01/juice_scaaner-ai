// Vulnerability Modules
CSRF — Change Password
Tests if the password change endpoint is vulnerable to Cross-Site Request Forgery. An attacker can trick a logged-in user into changing their password by sending a forged request from a malicious website.
Difficulty
⭐⭐⭐

// HOW THIS ATTACK WORKS

Attacker hosts a page at evil.com with a hidden request to /rest/user/change-password. When victim visits that page while logged in, the browser automatically sends their auth cookie — server accepts it and changes the password.

View Another User's Basket
Tests for Insecure Direct Object Reference (IDOR). The app fails to verify if the logged-in user owns the basket they are requesting, allowing access to any user's basket by changing the basket ID.
Difficulty
⭐⭐⭐⭐

// HOW THIS ATTACK WORKS

API endpoint /rest/basket/{id} accepts any basket ID. No check is done to verify if the requesting user owns that basket. Attacker simply iterates IDs to view other users' shopping carts.

Access Admin Section
Tests if admin-only pages and APIs are accessible to regular users. Broken access control allows non-admin users to reach administration panels and sensitive user data.
Difficulty
⭐⭐⭐⭐

// HOW THIS ATTACK WORKS

Admin routes like /administration and /api/Users are not properly protected. Any authenticated user can access them by directly navigating to the URL — no admin role check is enforced by the server.

CAPTCHA Bypass
Tests if the CAPTCHA implementation can be bypassed. The server sends the CAPTCHA answer in the API response itself, and the same CAPTCHA can be reused multiple times.
Difficulty
⭐⭐⭐⭐

// HOW THIS ATTACK WORKS

Juice Shop's CAPTCHA endpoint /rest/captcha/ returns the answer along with the question. An automated tool reads the answer directly and submits it — completely bypassing the CAPTCHA's purpose. Also the same CAPTCHA ID can be reused.

Customer Feedback Spam
Tests if the feedback endpoint has rate limiting or bot protection. Without it, an attacker can flood the feedback system with automated submissions.
Difficulty
⭐⭐⭐⭐

// HOW THIS ATTACK WORKS

The /api/Feedbacks/ endpoint has no rate limiting. A bot can rapidly submit hundreds of feedback entries — spamming reviews, flooding the database, or manipulating ratings — without any detection or blocking.

Extra Language Discovery
Tests for exposed hidden language files. Juice Shop contains a secret Klingon language translation file that reveals a hidden feature — discoverable through directory enumeration.
Difficulty
⭐⭐⭐⭐⭐

// HOW THIS ATTACK WORKS

The app serves all translation files under /assets/i18n/ publicly. By enumerating known language codes, an attacker discovers tlh.json (Klingon) — a hidden language not shown in the UI, revealing an undocumented feature of the application.
